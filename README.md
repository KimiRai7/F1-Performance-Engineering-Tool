# F1 Performance Engineering Tool

Python-based Formula 1 performance analysis toolkit using the FastF1 library.

## Main objective

Where is the lap time coming from?

# Development roadmap

- V0.1 - Core Lap Comparison
- V0.2 - Mini-Sector and Corner Analysis
- V0.3 - Qualifying Analysis
- V0.4 - Race Pace and Stint Analysis
- V0.5 - Tyre Degradation
- V0.6 - Driver Style Analysis
- V0.7 - Car Performance Fingerprint
- V0.8 - Strategy Analysis
- V0.9 - Automatic Weekend Report
